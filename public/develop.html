2M2A / OPEN SOURCE WORKSHOP

Make it your project.

Download the code, open it in VS Code, and develop on your own computer. The gallery, NASA data, fonts and research desk run without ChatGPT.

Download GitHub-ready project ↓

1. Run it locally

  1. Install Node.js 22 or newer.
  2. Extract the ZIP and open its FireLens folder in VS Code.
  3. Open Terminal → New Terminal and run:
npm start

Open http://127.0.0.1:5173/. Use Ctrl+C to stop. No package installation is required.

2. Connect your VT ARC model

The server now supports ARC’s Chat Completions API. In PowerShell, create your local configuration:

Copy-Item .env.example .env

In VS Code, open .env and fill in:

LLM_PROVIDER=vt-arc
ARC_API_KEY=your-own-key
ARC_MODEL=gpt-oss-120b

Get your personal key from VT ARC → User profile → Settings → Account → API keys. Restart npm start and use the Research desk.

Keep your key in the local .env. It is excluded from Git and the source ZIP. ARC keys are personal. Confirm with ARC before using your account to serve anonymous public visitors.

The connection format and failure handling have been tested with simulated responses. A live ARC response has not been evaluated. The public demo continues in evidence mode.

3. Put the code on GitHub

Create an empty repository in your GitHub account. The extracted folder includes the license, NASA data notices, Git ignore rules and an automated check workflow.

git init -b main
git add .
git commit -m "Import FireLens research gallery"

Then use the exact remote and push commands shown by your new GitHub repository. You can also use GitHub Desktop. The ZIP has no private keys or ChatGPT Site identity.

4. Choose your hosting

GitHub stores your code. The AI endpoint needs a Node server or Cloudflare Worker. GitHub Pages alone serves static files. The README includes independent hosting instructions and a ready Wrangler configuration.

Keep the current public demo while you develop. A push to your new GitHub repository does not automatically change the existing ChatGPT-hosted site.
