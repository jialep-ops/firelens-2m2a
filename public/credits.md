## NASA data
The seven public PSI investigations used in this project are PSI-25, PSI-26, PSI-69, PSI-98, PSI-99, PSI-100, and PSI-101. Their PSI metadata identifies the data license as Creative Commons Zero v1.0 Universal (CC0-1.0). Dataset names, DOIs, versions, original CSV filenames, and hashes are listed in data-provenance.json. The reviewed license can be read at https://creativecommons.org/publicdomain/zero/1.0/ . NASA report and webpage links in the source register provide additional research context; report-specific notices remain applicable. Documents and NASA photographs are not republished in the gallery.

## Original project material
The application, data-normalization code, original pixel drawings, original pixel typefaces, interface, and sound synthesis were created for this project with ChatGPT assistance. No external art, commercial fonts, game sprites, or third-party browser libraries are bundled. Python fontTools was used as a development tool to build the original TTF files (https://github.com/fonttools/fonttools); it is not shipped as a runtime library. Node.js and Python were used for development, and Sites hosts the application.

## AI disclosure
ChatGPT assisted source research, coding, normalization, visual design, verification, and drafting. Curated text remains subject to team and scientific review. Server-side VT ARC Chat Completions and OpenAI Responses API integrations are implemented, but no model credentials are currently configured. The deployed research assistant is labeled evidence mode. No live SI generation, trained predictive model, or autonomous safety assessment is claimed.
